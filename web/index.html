Alpaca Trade Analyzer

P&L, drawdown, benchmark and options-strategy analytics for your Alpaca account. Runs entirely in your browser: your keys go only to Alpaca's API, and the analysis runs locally in Python (WebAssembly).

Saved keys live in this browser's localStorage for , which every page on that origin can read. With a passphrase they're stored AES-GCM encrypted and you'll enter the passphrase on each visit.

Alpaca API keys can place trades. This page only makes GET requests, but you're trusting its code, so read the source or try a paper account first.
